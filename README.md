# Student Manager

An improved student table with modern UI, icons, and powerful functionality.

## Features
- Add, edit, and delete students
- Search and sort (ID, Name, Age)
- Select all and bulk delete
- Persistent data via localStorage
- CSV export
- Live stats (total, average age)
- Toast notifications
- Light/Dark theme toggle

## Usage
1. Open `main.html` in your browser (double-click the file on Windows).
2. Add students using the form. Use the toolbar to search, sort, and manage data.

## Notes
- Minimum name length: 3 characters
- Minimum age: > 18
- Duplicate (same name and age) entries are prevented
